# Security Policy

Please **do not** open a public GitHub issue for a security vulnerability.

Report it privately through [GitHub Security Advisories](https://github.com/pattrnlabs/grain/security/advisories/new),
or email **security@grain.tools**. Include:

- What you found and its potential impact
- Steps to reproduce
- The Grain version and connector involved, if relevant

We'll acknowledge your report and keep you updated as we investigate and fix it.
