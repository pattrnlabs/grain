# Grain examples

Runnable queries by database, plus how to connect an AI agent.

| Folder | What's in it |
| --- | --- |
| [`postgres/`](postgres/) | App-database ops checks + reporting queries |
| [`mysql/`](mysql/) | Same split as Postgres |
| [`elasticsearch/`](elasticsearch/) | Log triage and index health — not dashboards |
| [`duckdb/`](duckdb/) | Query a local CSV, zero setup |
| [`agents/`](agents/) | Connecting Claude Code, Cursor, and Copilot through Grain's MCP tools |

Open any `.sql` file in VS Code with Grain installed, put your cursor in a
query, and press `Ctrl+Enter` (`Cmd+Enter` on macOS).

Found a typo or a broken query? Small pull requests here are welcome — see
[CONTRIBUTING.md](../CONTRIBUTING.md).
